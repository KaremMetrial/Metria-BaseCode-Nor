# رحلة الأدمن كاملة

[فهرس الأدمن](README.md) · [الصلاحيات](permissions.md) · [تجهيز curl](../README.md)

1. جهّز حساب Admin والأدوار عبر إدارة النشر؛ لا توجد API لإنشاء Admin. في بيئة التطوير يوجد حساب seeder قابل للتهيئة، لا يُزرع في الإنتاج.
2. أرسل `POST /api/v1/admin/auth/login` بالبريد وكلمة المرور. [مثال الطلب والرد](authentication.md). احفظ data.token واقرأ `GET /api/v1/admin/profile`. الدخول لا يعيد مصفوفة صلاحيات؛ لا تستنتج الوصول لكل الميزات من نجاحه.
3. فعّل الأجهزة والإشعارات وSocket بنفس عقود الحساب المشتركة. أدوات الملف والجلسات تخص الأدمن الحالي؛ إدارة مستخدم آخر عبر users.
4. افتح `GET /api/v1/admin/users`. لاعتماد بائع pending أرسل `PATCH /api/v1/admin/users/{user}/status` بالطلب `{"status":"active"}` وصلاحية vendors.approve. الحالات الأخرى موضحة في [المستخدمين](users.md). إضافة role تحتاج super-admin ولا تستبدل الأدوار السابقة.
5. جهّز [الدول](countries.md) ثم [المحافظات](governorates.md) ثم [المدن](cities.md)، و[التصنيفات](categories.md). لا تضع معرفات ثابتة في تطبيق العميل؛ اجعله يقرأ الواجهات العامة.
6. افتح [الصفحات](pages.md)، اكتب translations.en وar، وارفع الصور بغاية page، واحفظ media_ids. احتفظ بـdraft_version وأرسله عند التعديل والنشر. بعد النشر تحقق عبر الواجهة العامة. نشر شروط تتطلب قبولًا يغيّر متطلبات onboarding؛ يجب أن يعرض العميل النسخة الجديدة قبل قبولها.
7. اضبط [إعدادات التواصل](contact-settings.md) مستخدمًا version الحالي. اقرأ [رسائل Contact Us](contact-messages.md) وانقل حالتها إلى reviewed أوclosed. الرد الحواري يتم عبر [Support Chat](support-chat.md).
8. في الدعم اقرأ المحادثة والرسائل، أرسل read marker بعد العرض، ثم أرسل ردًا بـclient_message_id فريد. المرفقات تُرفع قبل الرسالة. التعيين والحالة يستخدمان version؛ عند 409 أعد القراءة. التعيين لا يحجب المحادثة عن موظف آخر لديه support.read.
9. افتح [المدفوعات](payments.md) أو [المحافظ](wallets.md). الاسترداد في [ملف مستقل](refunds.md) ويحتاج صلاحية ومفتاح Idempotency؛ مبالغ المحفظة بوحدات صغرى. لا تعتبر نجاح قبول الطلب تأكيدًا نهائيًا من المزود.
10. خدمات التاجر المتقدمة في [MyFatoorah](MyFatoorah/README.md) بصلاحية مستقلة. مبالغها decimal major units، وسجلها لا يغيّر محفظة العميل تلقائيًا.
11. راقب [أوامر التشغيل](../Operations/commands.md) عند تعثر التسليم أوالدفع. logout يسحب جلسة الأدمن الحالية؛ افصل Socket محليًا كذلك.

كل صفحـة ميزة تتضمن endpoint والحقول والرد. 403 قد يعني عدم امتلاك الصلاحية رغم نجاح الدخول؛ لا تعِد تسجيل الدخول تلقائيًا بسبب كل 403. لا تستخدم توكن الأدمن في client endpoints للوصول نيابة عن العميل.
